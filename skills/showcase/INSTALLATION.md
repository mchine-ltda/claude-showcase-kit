# Installation

Two parts work together:

| Part | Where | What |
|---|---|---|
| The kit | wherever you clone it, e.g. `~/claude-showcase-kit` | The engine: template, capture, voice, audio, cover, QA, your projects and agency kit |
| The skill | `~/.claude/skills/showcase` | `SKILL.md`, these docs, the launcher `scripts/showcase.mjs` and `engine.json` (the kit's path) |

## Requirements

- **Claude Code.**
- **Node.js** 20.19+, 22.13+ or 24+.
- **git.**
- **Google Chrome or Microsoft Edge**, or `npx playwright install chromium` inside the kit.
- **About 2 GB of disk:**
  - `node_modules` ~1.3 GB;
  - the Kokoro voice model ~330 MB, downloaded on the first narration;
  - 15–70 MB per project.
- No system ffmpeg, Python or GPU.

## Install

```bash
git clone https://github.com/mchine-ltda/claude-showcase-kit.git
cd claude-showcase-kit
./install.sh            # Windows PowerShell: .\install.ps1
```

The installer does four things:
1. It installs the dependencies.
2. It creates `agency.config.json` from `agency.example.json`.
3. It installs the skill into `~/.claude/skills/showcase`. An older `website-showcase` skill from
   this kit is moved to `~/.claude/skills-backup/`.
4. It runs `doctor`.

Start a new Claude Code session in any repository and type `/showcase`.

Install for one project only: `./install.sh --project /path/to/repo` (or `.\install.ps1 -Project ...`).

## Your agency kit

Edit `agency.config.json` once: name, logo (a light, transparent PNG or SVG, e.g. in `agency/`),
outro lines, accent and `identity` (typefaces). Both the file and `agency/` stay out of git.

- **Fonts:** Geist, Geist Mono, Inter Tight and Instrument Serif are bundled (SIL OFL). For your own
  font, add its files to `agency/fonts/` and list them under `identity.display.files`. Only use fonts
  your licence allows in videos, and never commit licensed font files to a public repository.
- **Try it:** `npm run demo` renders the fictional Saltmarsh demo with your identity.

## Verify

```bash
node "$HOME/.claude/skills/showcase/scripts/showcase.mjs" where     # kit path, version, skill path
node "$HOME/.claude/skills/showcase/scripts/showcase.mjs" doctor
node "$HOME/.claude/skills/showcase/scripts/showcase.mjs" voices
```

In Claude Code, `/showcase` appears in the `/` menu of every repository. Claude also loads it for
requests like "make an Instagram reel of this project".

## Voices and keys

Kokoro needs nothing. For a cloud voice, set its key as a **user environment variable**, never in a
file:

| Provider | Variables |
|---|---|
| ElevenLabs | `ELEVENLABS_API_KEY` |
| Azure (Irish `en-IE-EmilyNeural`, `en-IE-ConnorNeural`) | `AZURE_SPEECH_KEY` + `AZURE_SPEECH_REGION` |
| OpenAI | `OPENAI_API_KEY` |

Then open a new terminal or Claude Code session.

## Privacy

Nothing private is ever committed:
- `projects/` (captures of client work, narration, renders, saved logins);
- `agency.config.json` and `agency/`;
- `.env`.

Demo-account sessions from `showcase login` live in `projects/<slug>/auth/`. Delete them when the
video is done.

## Update

```bash
cd claude-showcase-kit
git pull
./install.sh
```

Templates are frozen: an update never changes how an existing project renders. Check with
`npm run showcase -- compare <new render> <old render>`.

## Move or restore

- **Move:** move the kit folder and run `./install.sh` again (it rewrites `engine.json`), or set
  `SHOWCASE_ENGINE_DIR`.
- **Another computer:**
  1. clone and install;
  2. copy `agency.config.json`, `agency/` and the `projects/` you need from the old machine;
  3. re-capture any project whose capture you did not copy.

## Troubleshooting

- **`Engine not found`:** run `./install.sh` again or set `SHOWCASE_ENGINE_DIR`.
- **`has no dependencies installed`:** `npm install` in the kit.
- **`No Chromium browser available`:** install Chrome or Edge, or `npx playwright install chromium`.
- **`/showcase` is missing:** check that `~/.claude/skills/showcase/SKILL.md` exists, then start a new
  session.
- **A step was skipped:** `capture/report.md` says why. Use exact link text, `via` for dropdowns, or a
  selector.
- **Behind a login:** `showcase login <slug> --url <app>`, sign in with a demo account, close the
  window.
